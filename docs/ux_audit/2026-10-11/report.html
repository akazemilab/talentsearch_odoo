Talent Search UX Audit

Every page inside the product, in its real states and for each role that sees it, captured at phone width (375 px), desktop width (1280 px) and in dark mode. Each page was judged against ISO 9241-11, -110, -112, -125, -143, -171 and -210, ISO/IEC 25010 interaction capability, WCAG 2.2 AA and Persian right-to-left conventions.

What was fixed

Fix plan, now done

Most problems repeat across pages, so each fix is made once in a shared template or stylesheet. Waves 1 and 2 change only presentation and wording. Server-side access, consent, audit and share-level logic stay untouched.

Severity uses Nielsen's 0–4 scale: 4 blocks the task or excludes users, 3 is a major problem on a frequent task, 2 is minor, 1 is cosmetic. Effort: S is a style or wording change, M is a template restructure, L is a new component or flow.
